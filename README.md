# Event Reliability Monitor (ERM)
ERM hướng tới dashboard giúp backend developer điều tra event bất đồng bộ.
Mục tiêu 5 ngày: tài liệu thiết kế, frontend React dùng mock data và roadmap Backend 24 tuần.
Hiện tại chỉ hoàn thành chặng 0: workspace, Git và khảo sát môi trường.
Chưa có frontend chạy được hoặc hệ thống monitoring thật.
`demo-service/`, `monitor-service/`, `infrastructure/` chỉ chứa README placeholder.
Frontend sẽ được khởi tạo ở chặng 3A; chưa có lệnh npm để chạy dự án.
Xem [môi trường](docs/environment.md) và [tiến độ](docs/progress/STATUS.md).
Chỉ chuyển chặng khi người dùng duyệt; chưa tạo remote hoặc push GitHub.
